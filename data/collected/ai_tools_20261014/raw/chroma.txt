 Do unused credits rollover to the next month?
 Yes, in most cases your credits do not expire. The $100 of included usage in the Team plan does not rollover.
 What payment methods do you accept?
 Currently Chroma accepts credit card for Starter and Team plans. Enterprise plans have configurable billing methods.
 Can I change my plan in the middle of a billing cycle?
 Your plan change will be pro-rated to the calendar month. This applies to downgrades and upgrades.
 What happens if I exceed my plan's usage limits?
 There are 2 kinds of usage-limits. Customer set usage limits and Chroma set usage limits. Both result in a pausing of the service until the limit is changed.
 Can I export my data if I decide to leave?
 Chroma is an open-source product and egressing your data is easy.

## API

The core API is only 4 functions (run our [💡 Google Colab](https://colab.research.google.com/drive/1QEzFyqnoFxq7LUGyP1vzR4iLt9PpCDXv?usp=sharing)):

```python
import chromadb
# setup Chroma in-memory, for easy prototyping. Can add persistence easily!
client = chromadb.Client()

# Create collection. get_collection, get_or_create_collection, delete_collection also available!
collection = client.create_collection("all-my-documents")

# Add docs to the collection. Can also update and delete. Row-based API coming soon!
collection.add(
    documents=["This is document1", "This is document2"], # we handle tokenization, embedding, and indexing automatically. You can skip that and add your own embeddings as well
    metadatas=[{"source": "notion"}, {"source": "google-docs"}], # filter on these!
    ids=["doc1", "doc2"], # unique for each doc
)

# Query/search 2 most similar results. You can also .get by id
results = collection.query(
    query_texts=["This is a query document"],
    n_results=2,
    # where={"metadata_field": "is_equal_to_this"}, # optional filter
    # where_document={"$contains":"search_string"}  # optional filter
)
```

Learn about all features on our [Docs](https://docs.trychroma.com)
