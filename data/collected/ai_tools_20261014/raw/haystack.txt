 Introduction to Haystack
 Haystack is an open-source AI framework for building production-ready AI Agents , powerful RAG applications and scalable multimodal search systems . Build pipelines using reusable components, each responsible for specific tasks. Customize and extend pipelines to match your requirements. Learn more about Haystack and how it works.
 Welcome to Haystack
 To skip the introductions and go directly to installing and creating a search app, see Get Started .
 Haystack is an open-source AI orchestration framework that you can use to build powerful, production-ready applications with Large Language Models (LLMs) for various use cases. Whether you’re creating autonomous agents, multimodal apps, or scalable RAG systems, Haystack provides the tools to move from idea to production easily.
 Haystack is designed in a modular way, allowing you to combine the best technology from OpenAI, Google, Anthropic, and open-source projects like Hugging Face's Transformers.
 The core foundation of Haystack consists of components and pipelines , along with Document Stores, Agents , Tools, and many integrations. A pipeline is a graph you wire yourself, so it runs the same way every time; an agent hands step-by-step control to the LLM, trading that predictability for the ability to handle requests you didn't enumerate in advance. See Choosing Between Pipelines and Agents to decide which one your use case needs - and note that an agent can be a step inside a pipeline, and a pipeline can be a tool an agent calls, so it's rarely all-or-nothing. Read more about Haystack concepts in the Haystack Concepts Overview .
 Supported by an engaged community of developers, Haystack has grown into a comprehensive and user-friendly framework for LLM-based development.
 Start here ​ 
 New to Haystack? Follow this path:
 Installation - install the haystack-ai package.
 Get Started - build your first RAG pipeline and tool-calling agent.
 Core Concepts - components, pipelines, agents, and the other building blocks.
 Deployment - serve your pipeline or agent as an HTTP endpoint.
 Production Usage - evaluate, trace, and log it once it's running.
 Looking to scale with confidence?
 The Haystack Enterprise Platform gives you production infrastructure without the operational overhead:
 Built-in tracing — every deployed pipeline is traced automatically, no setup required
 Zero-downtime deploys — auto-scaling replicas absorb demand spikes without dropping traffic
 Built-in testing and analytics — a Playground for testing pipelines, plus dashboards for monitoring them in production
