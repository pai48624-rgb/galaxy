 분당 생성 비용은 얼마나 많은 크레딧이 필요한가요? 생성당 1분에 대략 600에서 625 크레딧이 소요됩니다.
 무료와 프리미엄 플랜의 차이점은 무엇인가요? 무료 플랜은 매월 무료로 생성할 수 있는 횟수를 제공하며, 프리미엄은 최고 품질의 음성 생성을 최대 200분까지 이용할 수 있는 크레딧을 제공합니다.
 월간 청구와 연간 청구 사이를 전환할 수 있나요? 네, 언제든지 월별 청구와 연간 청구 사이를 전환할 수 있습니다. 연간 청구로 전환하면 월별 청구에 비해 33%를 절약할 수 있습니다. 변경 사항은 다음 청구 주기에 적용됩니다.
 어떤 결제 방법을 받아들이나요? 우리는 안전한 결제 프로세서를 통해 모든 주요 신용카드 (Visa, MasterCard, American Express), 직불 카드, 그리고 다양한 지역 결제 방법을 모두 받아 들입니다.
 내 크레딧이 언제 초기화되나요? 크레딧은 매달 충전되고 초기화됩니다. 남은 크레딧은 텍스트를 음성으로 페이지에서 확인하세요.
 사용하지 않은 분들은 어떻게 되나요? 월별 할당량은 각 청구 주기의 시작에서 재설정됩니다. 사용하지 않은 분은 다음 달로 이월되지 않습니다. 청구 기간 내에 할당된 분을 사용하는 것을 권장합니다.
 API 접근을 제공하나요? 그렇습니다! 프리미엄 구독자는 우리의 유연한 선불 API에 접근할 수 있습니다. 자세한 문서와 가격 정보는 우리의 개발자 문서 에서 찾을 수 있습니다.
 제가 생성된 음성을 상업적 목적으로 사용할 수 있나요? 프리미엄 구독자는 상업적 목적으로 검증된 목소리(자신이 소유한)를 사용할 수 있습니다. 무료 플랜 사용자는 개인적이고 비상업적인 프로젝트에만 생성된 콘텐츠를 사용할 수 있습니다. 자세한 사용 권한에 대해서는 이용 약관을 확인해 주세요.

 Everything Fish Audio can do, and how to build with it
 Copy page Copy page 
 Fish Audio is a voice AI platform. Every core feature is available three ways: in the web app (no code), through the REST API , and via the official SDK . 
 ​ 
 Core features 
 Text to Speech
 Convert text into lifelike speech with the s2.1-pro , s2-pro , and deprecated s1 models. 
 Speech to Text
 Transcribe audio with transcribe-1-pro : multi-speaker conversations, long recordings, emotion cues, and optional timestamps. 
 Voice Cloning
 Clone a voice instantly from a clip, or train a persistent model. 
 Realtime Streaming
 Stream audio as it generates, for voice agents and live apps. 
 Manage Voices
 List, inspect, update, and delete your voice models. 
 ​ 
 Also in the web app 
 These run in the browser, no code required. See the Platform guide . 
 Professional Voice Clone
 Clone a real, verified voice at studio quality, then release it. 
 Voice Design
 Design a voice from a plain-text description. Best for original characters. 
 Voice Changer
 Transform existing audio into a different voice. 
 Story Studio
 Produce multi-speaker, long-form audio: audiobooks and narration. 
 Music & Sound Effects
 Generate music and cinematic sound effects from a prompt. 
 Audio Separation
 Split audio into stems, and related processing utilities. 
 ​ 
 Models 
 These text-to-speech models power most capabilities: 
 s2.1-pro : the recommended production model, with improved quality, latency, and throughput over S2-Pro.
 s2.1-pro-free : the same model at $0 for testing, prototyping, development, and smaller businesses, without TTFA or DPA guarantees.
 s2-pro : the previous-generation S2 model, with multi-speaker and natural-language expression control.
 s1 : the previous generation, with (parenthesis) emotion tags. S1 is deprecated and will be retired on December 31, 2026. After that date, requests that specify s1 are served by s2.1-pro . See Migrate from S1 .
 For speech to text, select the model with the model header on POST /v1/asr : 
 transcribe-1-pro : the recommended model, for everything from short clips to multi-speaker conversations (speaker markers and speaker turns) and long recordings, with inline emotion cues. Send model: transcribe-1-pro explicitly.
 transcribe-1 : general transcription of short recordings. A request whose model header is missing or not an exact match is served by this model.
 See Models Overview and Choosing a Model for the full lineup and languages, and Speech to Text for transcription formats and limits.

## Quick Start

### For Human

- [Installation](https://speech.fish.audio/install/): environment setup, download weights, Docker deployment
- [Inference](https://speech.fish.audio/inference/): command line, API server, WebUI

> [!IMPORTANT]
> **We strongly recommend SGLang-Omni for users who care about efficiency; see the [SGLang-Omni README](https://github.com/sgl-project/sglang-omni/blob/main/sglang_omni/models/fishaudio_drama_3/README.md).**
>
> **For vLLM Omni server, please read [vLLM-Omni Fish Speech S2 Pro Recipe](https://github.com/vllm-project/vllm-omni/blob/main/recipes/fishaudio/Fish-Speech-S2-Pro.md) and the [User Guide](https://github.com/vllm-project/vllm-omni/blob/main/docs/user_guide/examples/online_serving/text_to_speech.md#fish-speech-s2-pro).**

### For LLM Agent

```
Install and configure Fish Audio Drama 3 (or S2-Pro) by following the instructions here: https://speech.fish.audio/install/
```
