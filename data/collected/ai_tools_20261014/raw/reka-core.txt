 Getting Started 
 Reka API Documentation
 Copy page 
 The Reka API serves Reka models and a curated selection of open models, including DeepSeek, GLM, Qwen and Gemma, through one OpenAI-compatible endpoint. You choose the model for each request, and Reka runs it on infrastructure it operates, from the API to the GPUs.
 Point your existing OpenAI client at https://api.reka.ai/v1 , use your Reka API key, and pick a model from the model list .
 First API call 
 curl https://api.reka.ai/v1/chat/completions \ 
 -H " Authorization: Bearer $REKA_API_KEY " \ 
 -H " Content-Type: application/json " \ 
 -d ' { 
 "model": "reka-flash-3", 
 "messages": [{"role": "user", "content": "Why is the sky blue?"}] 
 } '
