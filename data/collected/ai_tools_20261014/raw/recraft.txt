 구독 크레딧과 충전 크레딧의 차이점은 무엇인가요? 구독 크레딧은 요금제에 포함되며 각 결제 주기가 시작될 때 재설정됩니다. 사용하지 않은 크레딧은 이월되지 않습니다.
충전 크레딧은 별도로 구매하고 만료되지 않으며 월별 크레딧이 소진되면 자동으로 사용됩니다. Teams 작업 영역에서는 충전 크레딧이 모든 시트에서 공유됩니다. 충전은 Basic, Pro 및 Teams 요금제에서 사용할 수 있습니다. 
 운영 비용은 얼마입니까? 크레딧 비용은 작업 유형과 사용된 모델에 따라 다릅니다.
자세한 내용은 외부 모델 가격도 참조하세요. 
 어떤 결제 방법이 허용되나요? Recraft는 신용카드, 직불카드, 은행 송금을 지원합니다. 결제는 Stripe를 통해 안전하게 처리됩니다. 
 환불받을 수 있나요? 가장 최근 결제가 지난 30일 이내에 이루어졌고, 해당 결제 이후 크레딧을 사용하지 않았거나 계정 생성 이후 사용한 크레딧이 총 30개 미만인 경우, 당사의 재량에 따라 환불을 제공할 수 있습니다. 검토를 요청하려면 help@recraft.ai 로 지원팀에 문의하세요. 환불은 원래 결제 수단으로 이루어지며, 결제 및 환불에 대한 추가 세부정보는 서비스 약관 에서 확인할 수 있습니다.
계정이 삭제된 후에는 요청을 검토하는 데 필요한 기록에 더 이상 접근할 수 없으므로 환불을 처리할 수 없습니다. 계정을 삭제하기 전에 문의해 주세요. 
 구독을 어떻게 취소하나요? 언제든지 취소할 수 있습니다. 
 — 오른쪽 상단의 프로필을 클릭하고 '구독 관리'를 선택하세요. 
 — “계획 취소”를 클릭하고 확인하세요. 
 귀하의 계획은 현재 청구 기간이 끝날 때까지 활성 상태로 유지됩니다. 취소 후에도 유료 구독 중에 생성된 이미지는 비공개로 유지되며 귀하의 소유입니다. 
 무료 플랜에서 내가 생성한 이미지는 누가 소유하나요? Free 플랜에서 생성된 이미지는 Recraft가 소유합니다. 해당 이미지는 커뮤니티 갤러리에 공개되며 상업적 사용이 허가되지 않습니다. 예를 들어, 일반적으로 소유권 증명이 필요한 스톡 플랫폼에는 등록할 수 없습니다. 
 유료 플랜으로 생성한 이미지는 누가 소유하나요? 유료 플랜은 구독하는 동안 생성된 모든 이미지에 대한 완전한 소유권과 상업적 권리를 부여합니다. 마케팅, 브랜딩, 제품 포장 또는 기타 전문적인 목적으로 자유롭게 사용할 수 있습니다. 이미지는 비공개로 유지되며 커뮤니티 갤러리에 표시되지 않습니다. 
 구독을 취소하면 내 이미지는 어떻게 되나요? 유료 구독 중에 생성된 이미지는 구독이 종료된 후에도 비공개로 유지되며 귀하의 소유입니다. 공개되지 않습니다. 귀하는 취소 후에도 해당 이미지에 대한 완전한 소유권과 상업적 권리를 유지합니다. 
 Recraft는 API를 제공하나요? 예. Recraft API는 이미지 및 벡터 생성, 편집, 배경 제거, 인페인팅, 아웃페인팅, 배치 작업, 비동기 처리에 대한 프로그래밍 방식의 접근을 제공합니다. 내부 도구, 고객 대상 기능 또는 대규모 비주얼 파이프라인을 구축하는 개발자를 위해 설계되었습니다. 
 API를 통해 어떤 모델을 사용할 수 있나요? V2, V3, V4 및 V4.1 세대의 모든 모델은 API를 통해 사용할 수 있습니다. 자세한 내용은 API 문서 에서 확인할 수 있습니다. 
 API 사용량은 어떻게 청구되나요? API 사용량은 요청당 소비된 API 단위를 기준으로 청구됩니다. 가격은 작업 및 출력 유형에 따라 다릅니다. 전체 세부정보는 API 가격 책정 문서 에서 확인할 수 있습니다. 
 API 단위는 환불 가능합니까? API Units는 선불이며 구독 크레딧과 별도로 구매됩니다. API Unit 패키지는 관련 법률에서 요구하는 경우를 제외하고 취소 및 환불이 불가능하며, 구매한 API Units는 만료되지 않습니다. 이는 위에서 설명한 구독 플랜에 대해 당사가 재량으로 제공할 수 있는 환불과는 별개입니다. 자세한 내용은 개발자 약관 및 API 가격 문서 에서 확인할 수 있습니다.

 Premium image generation and editing tool.
A revolutionary AI model that thinks in design language. 
 Founded in the US in 2022 and headquartered in London, UK, Recraft enables designers to create and perfect their visuals. 
‍
Recraft is an AI tool for professional designers, illustrators, and marketers. It lets creators easily generate and iterate original images, vector art, illustrations, icons, and 3D graphics with AI. 
‍
Among Recraft's core strengths is its exceptional image generation quality, including generation images with text of any size and length. And with unique graphic design generator it is now possible to set the exact positions of text and different elements in the image. Plus, creators can generate images with consistent brand style, and vector art — unique capabilities vital for graphic design space. 
‍
Packed with dozens of features and an infinite canvas for real-time collaboration, Recraft is trusted by over 3 million users across 200 countries, including designers from most innovative companies like Ogilvy, HubSpot, Netflix, Asana, and Airbus. Recraft has helped creators generate more than 350 million images.
The team behind Recraft is committed to making the product essential, daily tool for every designer, setting the industry standard. Recraft's ongoing mission is to ensure that creators can have full control over their creative process with AI, providing them with innovative tools to turn ideas into reality.
