 자주 묻는 질문 
 Atoms란 무엇인가요?
 Atoms는 아이디어를 실제 제품으로 구현하는 AI 기반 개발 플랫폼입니다. 제품 관리자, 엔지니어, 데이터 과학자 등으로 구성된 AI 팀이 멀티 에이전트 워크플로우를 통해 기획부터 구축, 테스트, 출시까지 모든 과정을 처음부터 함께 수행합니다.
 Atoms로 무엇을 만들 수 있나요?
 설명할 수 있다면 Atoms AI가 구축할 수 있습니다. 인기 있는 프로젝트는 다음과 같습니다:
 SaaS: 사용자 로그인 및 실시간 데이터베이스 저장을 갖춘 구독 기반 제품
 내부 도구: 비즈니스 데이터를 관리하는 대시보드 및 도구
 개인 웹사이트: 아름다운 포트폴리오, 블로그 또는 개인 브랜드 사이트
 E-commerce: 전환을 높이는 상품 페이지, 안전한 결제를 위한 Stripe 연동
 Atoms를 사용하려면 코딩이나 기술적 지식이 필요한가요?
 아니요. Atoms AI는 자연어 채팅으로 빌드하는 'Vibe Coding' 방식을 지향합니다. 원하는 내용을 설명할 수만 있다면 무엇이든 만들 수 있습니다. 전문가를 위한 코드 에디터도 제공되지만, 시작하는 데 기술적인 지식은 전혀 필요하지 않습니다.
 Atoms 앱이나 웹사이트는 어떻게 배포되나요?
 클릭 한 번으로 충분합니다. Atoms AI가 호스팅과 서버 구성을 대신 처리해 드립니다. 준비가 되면 즉시 라이브 URL을 게시하세요. 복잡한 설정은 필요 없습니다.
 크레딧 시스템은 어떻게 작동하며 요금 정책은 투명한가요?
 Atoms는 투명한 크레딧 시스템을 운영합니다. 기능 생성, 테스트, 배포 등 AI가 수행하는 작업의 복잡도에 따라 크레딧이 차감됩니다. 대시보드에서 크레딧 잔액과 사용 내역을 실시간으로 확인할 수 있어 예산을 효율적으로 관리할 수 있습니다.
 Atoms는 유료 고객을 확보하는 데 어떤 도움이 되나요?
 Atoms AI는 단순히 앱을 완성하는 것을 넘어 출시 첫날부터 성장을 가속화할 수 있도록 돕습니다. SEO 페이지를 출시하고 최적화 작업을 자동화할 수 있습니다. Stripe 결제가 기본 내장되어 있어, 게시와 동시에 수익을 창출할 수 있습니다.
 Atoms로 제작한 결과물의 소유권은 저에게 있나요?
 네. 언제든지 코드를 내보내거나 프로젝트를 GitHub와 동기화할 수 있어, 구축과 성장 과정 전반에서 항상 모든 제어권을 유지할 수 있습니다. 코드를 내보낸 후에는 로컬에서 실행하거나 자체 인프라에 호스팅할 수 있어 제품 성장에 맞춰 유연하게 대처할 수 있습니다.
 Atoms는 이미 사용 중인 도구와 연동할 수 있나요?
 네. Atoms AI는 범용 도구와의 연동을 지원하므로 기존 워크플로우에 바로 통합할 수 있습니다. 이를 통해 단순한 데모가 아닌 실제 비즈니스에 즉시 투입 가능한 결과물을 만들 수 있습니다.
 Atoms는 제 모국어를 지원하나요?
 네. Atoms는 자연어 입력을 지원하며 여러 언어로 작업할 수 있습니다. 모국어로 아이디어를 구상하고 채팅하며 빌드할 수 있어 끊김 없는 개발 경험을 제공합니다.

 무료 플랜: $0 / 월 크레딧: 하루 15 / 월 25

 유연한 요금제(월별): 500 → $100(기본), 1000 → $200, 1500 → $300 , 최대 10000
 하이라이트: 더 높은 정확도와 성능, 더 넓은 저장 공간을 제공합니다. 레이스 모드는 정확도를 최대 3배까지 높여줍니다

 언제든지 플랜을 변경할 수 있나요? 변경 사항은 언제 적용되나요?
 네, 언제든지 변경할 수 있습니다. 
 업그레이드: 결제 후 즉시 적용되지만 결제 주기는 초기화되지 않습니다. 기존 결제 주기를 바탕으로 유지됩니다. 업그레이드 시에는 차액만 결제하시면 됩니다.
 예시: $20 플랜을 구매하여 10일간 사용하고 20일이 남은 상황에서 지금 $100 플랜으로 업그레이드하면, 남은 20일 동안 새 플랜이 즉시 적용됩니다. 또한 사용하지 않은 기존 크레딧은 다음 주기로 이월됩니다. 개월 (이월은 1개월 동안만 유효하며, 영구적이지 않습니다). 
 다운그레이드: 현재 결제 주기가 끝난 다음 날부터 적용됩니다. 저장 용량이 줄어들 경우, Atoms 이용에 차질이 없도록 프로젝트를 내보내거나 정리하실 수 있도록 사전에 안내해 드립니다. 다운그레이드는 환불이 불가능하며 현재 결제 주기가 종료되어야 적용됩니다.
 예시: $100 플랜을 구매하여 10일간 사용하고 20일이 남은 경우, $20 플랜으로의 다운그레이드는 현재 결제 주기가 끝난 후(20일 뒤)에 적용됩니다. 기존 $100 플랜이 만료된 다음 날부터 $20 플랜이 시작되며, 사용하지 않은 크레딧은 다음 주기로 이월됩니다. 개월 (이월은 1개월 동안만 유효하며, 영구적이지 않습니다). 
 크레딧이 부족하면 추가로 구매할 수 있나요?
 언제든지 다음에서 더 높은 플랜으로 업그레이드할 수 있습니다: 설정 → 플랜 및 크레딧 페이지 또는 가격 → 결제 페이지에서 크레딧을 추가로 충전할 수 있으며, 이는 즉시 적용됩니다. 
 사용하지 않은 크레딧은 초기화(소멸)되나요?
 특정 상황에 따라, 사용하지 않은 크레딧은 다음과 같은 경우 다음 결제 주기로 자동 이월됩니다 (이월은 한 달만 가능하며 영구적이지 않습니다): 
 업그레이드 후 남은 크레딧
 특별한 경우 일일 고정 크레딧(15) 외에 시스템에서 추가로 지급하는 보너스 크레딧입니다
 신규 사용자 초대 보상 크레딧
 리딤 코드로 획득한 크레딧
 다운그레이드/업그레이드가 제 데이터에 영향을 주나요?
 다운그레이드/업그레이드로 인해 저장 용량이 줄어들 경우, Atoms를 정상적으로 이용하실 수 있도록 파일 백업이나 삭제 안내를 드릴 예정입니다. 
 구독은 자동 갱신되나요?
 네. Pro 및 Max 플랜은 다음을 통해 직접 다운그레이드하지 않는 한 매달 자동으로 갱신됩니다: 설정 → 플랜 및 크레딧 페이지 또는 가격 → 결제 다음 결제 주기가 시작되기 전 페이지. 
 언제든지 구독을 취소할 수 있나요?
 네, 다음을 통해 언제든지 현재 플랜을 Free 플랜으로 다운그레이드할 수 있습니다: 설정 → 플랜 및 크레딧 페이지 또는 가격 → 결제 페이지. 다운그레이드는 현재 결제 주기가 끝난 다음 날부터 적용됩니다. 
 플랜 및 결제 정보는 어디에서 확인할 수 있나요?
 현재 플랜, 크레딧 등급, 남은 잔액, 결제 내역은 언제든지 다음에서 확인할 수 있습니다: 설정 → 플랜 및 크레딧 페이지 또는 가격 → 결제 페이지. 
 크레딧이란 무엇이며 어떻게 사용되나요?
 크레딧은 서비스 이용에 사용되는 포인트이며 일일 보너스 크레딧, 월간 구독 크레딧, 보상 크레딧 등을 포함합니다.
 크레딧은 일일 크레딧(일일 15개), 구독 크레딧, 보너스 크레딧 순으로 자동 차감됩니다.

## Software Company as Multi-Agent System

1. MetaGPT takes a **one line requirement** as input and outputs **user stories / competitive analysis / requirements / data structures / APIs / documents, etc.**
2. Internally, MetaGPT includes **product managers / architects / project managers / engineers.** It provides the entire process of a **software company along with carefully orchestrated SOPs.**
   1. `Code = SOP(Team)` is the core philosophy. We materialize SOP and apply it to teams composed of LLMs.

## Get Started

### Installation

> Ensure that Python 3.9 or later, but less than 3.12, is installed on your system. You can check this by using: `python --version`.  
> You can use conda like this: `conda create -n metagpt python=3.9 && conda activate metagpt`

```bash
pip install --upgrade metagpt
# or `pip install --upgrade git+https://github.com/geekan/MetaGPT.git`
# or `git clone https://github.com/geekan/MetaGPT && cd MetaGPT && pip install --upgrade -e .`
```

**Install [node](https://nodejs.org/en/download) and [pnpm](https://pnpm.io/installation#using-npm) before actual use.**

For detailed installation guidance, please refer to [cli_install](https://docs.deepwisdom.ai/main/en/guide/get_started/installation.html#install-stable-version)
 or [docker_install](https://docs.deepwisdom.ai/main/en/guide/get_started/installation.html#install-with-docker)

### Configuration

You can init the config of MetaGPT by running the following command, or manually create `~/.metagpt/config2.yaml` file:
```bash
# Check https://docs.deepwisdom.ai/main/en/guide/get_started/configuration.html for more details
metagpt --init-config  # it will create ~/.metagpt/config2.yaml, just modify it to your needs
```

You can configure `~/.metagpt/config2.yaml` according to the [example](https://github.com/geekan/MetaGPT/blob/main/config/config2.example.yaml) and [doc](https://docs.deepwisdom.ai/main/en/guide/get_started/configuration.html):

```yaml
llm:
  api_type: "openai"  # or azure / ollama / groq etc. Check LLMType for more options
  model: "gpt-4-turbo"  # or gpt-3.5-turbo
  base_url: "https://api.openai.com/v1"  # or forward url / other llm url
  api_key: "YOUR_API_KEY
