 Frequently asked questions
 What are the system requirements for self-hosting? 
 To self-host W&B, you’ll need Docker and Python installed on your machine.
 The server can run on Linux, macOS, or Windows systems that meet these requirements.
 How do I get started with self-hosting? 
 To get started with self-hosting, you’ll need to install Docker and Python on your machine.
 You can then use the command line to start the server.
 The server can run on Linux, macOS, or Windows systems that meet these requirements.
 What is the difference between self-hosting and cloud-hosted? 
 Self-hosting allows you to run Weights & Biases on your own infrastructure, giving you full control over your data and privacy.
 Cloud-hosted is a fully managed service that provides you with a scalable and reliable platform.
