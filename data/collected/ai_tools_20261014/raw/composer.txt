 Cursor 2.0 및 Composer 소개
 읽는 데 3분 
 목차
 ↑ Composer 소개

 시작하기 
 오늘 우리는 Cursor를 에이전트와 함께 작업하기에 최적의 환경으로 만들어 줄 두 가지 큰 업데이트를 출시합니다. 바로 첫 코딩 모델인 Composer, 그리고 여러 에이전트를 병렬로 활용하기 위한 새로운 인터페이스입니다.
 # Composer 소개
 Composer는 동급 수준의 모델보다 4배 빠른 최첨단 모델입니다.
 이 모델은 Cursor에서 지연이 낮은 Agent 기반 코딩을 위해 설계되었으며, 대부분의 상호작용을 30초 이내에 완료합니다. 초기 테스트 참여자들은 이 모델과 빠르게 반복 작업을 할 수 있는 점을 매우 만족스러워했고, 여러 단계를 거치는 코딩 작업을 맡길 수 있을 만큼 신뢰했습니다.
 Composer는 코드베이스 전체를 아우르는 시맨틱 검색을 포함한 강력한 도구 세트로 학습 되었으며, 덕분에 대규모 코드베이스를 이해하고 그 안에서 작업하는 능력이 훨씬 뛰어납니다.
 # 멀티 에이전트 인터페이스
 Cursor를 열면 가장 먼저 새 인터페이스가 눈에 들어올 것입니다.
 이제 인터페이스는 파일이 아니라 에이전트를 중심으로 처음부터 다시 설계되어, 더 집중된 환경을 제공합니다. 사용자는 원하는 결과에만 집중하고, 세부적인 작업은 에이전트에게 맡길 수 있습니다. 코드 속을 깊이 살펴봐야 할 때도, 새 레이아웃에서 파일을 쉽게 열 수 있고, 필요하다면 언제든 클래식 IDE로 전환할 수 있습니다.
 Cursor 2.0은 git worktree 또는 원격 머신을 기반으로, 여러 에이전트를 서로 간섭 없이 병렬로 실행할 수 있도록 설계되었습니다. 여러 모델이 동일한 문제를 각각 풀어 보게 한 뒤 최선의 결과를 선택하면, 특히 난도가 높은 작업에서 최종 결과물이 크게 개선된다는 것도 확인했습니다.
 코딩에 에이전트를 더 많이 활용하면서, 코드 리뷰와 변경 사항 테스트라는 두 가지 새로운 병목 지점이 나타나는 것을 확인했습니다. Cursor 2.0에서는 이 두 가지를 해결하기 시작했습니다. 에이전트가 만든 변경 사항을 빠르게 검토하고, 필요할 때 코드 속으로 더 깊이 파고들 수 있도록 훨씬 더 쉽게 만들었습니다. 또한 Cursor가 자신의 작업을 직접 테스트하고 올바른 최종 결과를 낼 때까지 반복 실행할 수 있도록, 네이티브 브라우저 도구도 새로 구축했습니다.
 # 시작하기
 Cursor 2.0을 지금 사용하실 수 있습니다: cursor.com/download .
 전체 changelog 에서 모든 기능을 확인해 보세요.

 질문과 답변
 나에게 맞는 플랜은 무엇인가요? ↓ ↑ 
 AI를 처음 사용하는 사용자에게는 Premium을, 매일 에이전트를 사용하는 사용자에게는 Super를, 사용량이 많은 고급 사용자에게는 Ultra를 권장합니다. AI 사용량이 적은 소셜 미디어 크리에이터에게는 Plus를 권장합니다. 다른 사람들과 협업하는 전문가에게는 Teams 플랜을 권장하며, 인보이스 청구, 공유 사용량 또는 고급 보안이 필요한 대규모 조직에는 기업 플랜이 적합합니다.
 결제 옵션에는 어떤 것이 있나요? ↓ ↑ 
 셀프 서비스 플랜은 주요 신용카드와 직불카드를 모두 지원합니다. 인보이스 청구 및 계좌이체를 원하시면, 기업 플랜에 대해 논의할 수 있도록 문의하기 를 이용해 주세요. 
 사용량 한도는 어떻게 적용되나요? ↓ ↑ 
 모든 티어에는 Cursor와 Grok에서 함께 사용하는 AI 사용량 풀이 포함됩니다. Grok에서는 이 풀을 Chat, Imagine, Voice, Bot에 사용할 수 있습니다. 상위 티어일수록 더 큰 풀이 제공되며, 사용 요금은 제품별로 다릅니다. 사용 한도는 매주 갱신되므로 하루 동안 많이 사용하더라도 한 달 치 사용량이 한꺼번에 소진되지는 않습니다.
 기본 제공 사용량을 모두 소진하면 추가 충전으로 계속 사용하거나 사용 한도가 갱신될 때까지 기다릴 수 있습니다. 설정에서 남은 사용량을 언제든 확인할 수 있습니다. 자세한 내용은 문서 를 참조하세요.
 내 플랜에 Grok API가 포함되나요? ↓ ↑ 
 유료 요금제에는 Grok API 접근 권한이 포함됩니다. API 사용량은 표준 모델 요금에 따라 별도로 청구되며, 사용자의 플랜에 포함된 사용량 풀에서 차감되지 않습니다. 모델 요금제 를 참조하세요. 
 어떤 모델을 지원하나요? ↓ ↑ 
 Plus에는 Grok 모델만 포함됩니다. Premium 이상 요금제에는 넉넉한 Grok 모델 사용량이 포함되지만, 서드파티 모델의 기본 제공 사용량은 포함되지 않습니다. 서드파티 모델은 Cursor에서 API 정가로 계속 사용할 수 있습니다. 사용자는 사용한 만큼만 요금을 지불하며, 지출 한도를 설정해 요금을 관리할 수 있습니다.
 가격에 세금이 포함되어 있나요? ↓ ↑ 
 모든 가격은 세금 별도입니다. 자세한 정보는 구독 약관 을 확인하세요. 
 조직에서 Cursor의 사용량을 확인하고 관리하려면 어떻게 해야 하나요? ↓ ↑ 
 관리자는 관리자 대시보드 를 통해 사용량 정보와 주요 지표를 확인할 수 있습니다. 
 Cursor는 내 데이터를 어떻게 사용하나요? ↓ ↑ 
 Privacy Mode는 설정에서 켜거나 팀 관리자가 켤 수 있습니다. 이 기능이 켜지면 당사와 모델 제공업체가 코드 데이터를 학습에 사용하지 않도록 보장합니다. 자세한 내용은 Security 페이지에서 확인할 수 있습니다. 
 리셀러나 타사를 통해 Cursor를 구매할 수 있나요? ↓ ↑ 
 아니요. 구독은 X Subscription Corp.에서만 직접 판매합니다. 당사는 어떤 리셀러나 타사 판매자도 공식 판매자로 인정하지 않습니다. 다른 경로로 구매한 구독은 정식 구독이 아니며, 사기로 판매되었거나 보안에 취약하거나 당사 시스템을 악용해 취득한 것일 수 있습니다. 이러한 계정은 언제든지 정지되거나 해지될 수 있습니다. 접근 권한과 보안을 보호하려면 반드시 공식 웹사이트에서 X Subscription을 구매하세요.
