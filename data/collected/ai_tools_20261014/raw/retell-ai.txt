 Introduction to Retell
 Copy page Copy page 
 Retell is a platform to build, test, deploy, and monitor AI voice and chat agents with telephony, prompts, tools, and analytics built in.
 Copy page Copy page 
 Retell runs the telephony, speech, and language model layers, so you configure the agent instead of connecting providers. 
 ​ 
 Build 
 Retell agents use a single prompt or a conversation flow, with call handling, a knowledge base, and integrations built in. The build overview covers the rest of the configuration. 
 ​ 
 What voice agent should I start with? 
 1
 Start with a single prompt
 Describe the whole task in one prompt and let the model run the conversation. A task with several steps still fits in one prompt. 
 2
 Test it before changing anything
 Try it in the Playground and with simulation tests. If it works reliably, keep it as a single prompt. 
 3
 Switch to conversation flow when you need more contro
