 01/ 
 Foundry Tools의 Azure 음성(이전의 Azure AI 음성)란? 
 Azure 음성은 Foundry Tools(이전의 Azure AI 서비스)의 일부로, 음성 텍스트 변환, 텍스트 음성 변환, 번역, 화자 인식 API를 제공합니다. 이전에는 Azure AI 음성으로 알려져 있었습니다. 
 02/ 
 Azure AI 음성이 이제 Foundry Tools의 Azure 음성으로 불리는 것을 확인했습니다. 서비스가 어떻게 바뀌나요? 
 예,이전의 많은 Azure AI 서비스를 Foundry Tools로 다시 브랜딩하고 있습니다. 이러한 변화는 Foundry의 광범위한 플랫폼 통합을 반영하며, 이러한 서비스가 이제 에이전트 AI 애플리케이션을 빌드하기 위한 핵심 도구로 자리 잡았음을 의미합니다.
 Foundry Tools의 Azure 음성은 여전히 음성 인식, 텍스트 음성 변환, 번역 같은 강력한 기능을 그대로 제공하지만, 이제는 지능형 에이전트를 만드는 개발자를 위한 통합 도구 키트의 일부입니다. 
 이 브랜드 변경은 이러한 API가 Foundry 에코시스템에 어떻게 적합한지 명확히 하고 이를 더 쉽게 검색하고, 오케스트레이션하고, 최신 AI 워크플로에 통합하는 데 도움이 됩니다. 
 03/ 
 Azure 음성은 어떤 기능을 지원하나요? 
 Azure 음성은 음성을 텍스트로 변환, 텍스트를 음성으로 변환, 음성 번역을 비롯한 다양한 기능을 제공합니다. 이러한 기능은 C#, C++ 및 Java를 비롯한 여러 프로그래밍 언어로 SDK를 통해 제공됩니다.

 04/ 
 Azure AI 음성에서 음성 번역에 지원되는 언어는 무엇인가요? 
 음성은 계속 증가하는 언어 집합을 지원합니다. 지원되는 언어는 현재 목록 을 참조하세요. 
 05/ 
 Azure OpenAI의 GPT 모델을 사용하여 음성 텍스트 변환을 사용해 지능형 솔루션을 만드는 방법에는 어떤 것들이 있나요? 
 고객들은 Foundry Tools를 사용하여 흥미로운 애플리케이션을 빌드하고 있습니다. 대화형 AI, 통화 후 분석 및 비디오 요약을 비롯한 사용 사례를 확인하려면 Azure 음성을 시작하세요.
