 자주 묻는 질문
 Pro는 Free와 어떻게 다른가요? Free 요금제는 주간 사용량이 제한된 상태로 최고의 AI 모델에 대한 액세스를 제공합니다. Pro는 모든 한도를 상향하고 Perplexity Computer, PitchBook 및 Statista와 같은 프리미엄 데이터 소스, 웹·파일·앱 전반의 검색, 모델 카운슬, 쿼리별 선호 모델 선택 기능을 추가합니다.
 왜 Pro 대신 Max를 선택해야 하나요? Max는 부담이 크고 지속적인 작업을 위해 설계되었습니다. Pro의 모든 기능을 포함하면서 Deep Research, 애셋 생성, 파일 업로드 한도가 더 높고, 매월 더 많은 동영상 제작과 여러 번의 Model Council 실행을 제공합니다.
 각 요금제에는 어떤 AI 모델이 포함되나요? Perplexity는 ChatGPT, Google Gemini, Anthropic Claude, NVIDIA Nemotron 등 여러 최고의 모델을 오케스트레이션하고 쿼리마다 가장 적합한 모델을 선택합니다. Pro와 Max에서는 모두 선호하는 모델을 선택할 수 있습니다. Max는 심층 조사와 대규모 데이터셋을 위한 고급 추론 모델을 추가로 제공합니다.
 Perplexity는 출처를 어떻게 인용하나요? 모든 답변에는 각 주장이 정확히 어디에서 나왔는지 보여주는 인라인 인용이 포함됩니다. Pro와 Max는 PitchBook, Statista, S&P Capital IQ를 비롯해 금융 및 시장 인텔리전스 작업을 위한 프리미엄 데이터 소스를 추가합니다.

 This page shows pricing information to help you understand API costs. For billing setup , payment methods, and usage monitoring, visit the Admin section . For rate limits , see the Rate Limits & Usage Tiers page. 
 ​ 
 Estimate your cost 
 ​ 
 Orchestrator API Pricing 
 Orchestrator API usage is billed per token at each model’s published rates — there are no per-request fees. Every model has its own input and output rate, with cache reads billed at the model’s discounted cache-read rate and reasoning tokens billed at the output rate. You are always billed at the requested model’s rates, regardless of how the request is served. 
 See Orchestrator Models & Pricing for the full per-model rate card, including cache-write rates and long-context pricing. 
 ​ 
 Agent API Pricing 
 The Agent API provides access to third-party models from providers including OpenAI, Anthropic, Google, xAI, Z.AI, Moonshot AI, and NVIDIA with transparent, token-based pricing at each model’s published rates. 
 ​ 
 Model Pricing 
 Agent API pricing varies by provider and model, with each provider offering multiple models at different price points. 
 View Complete Third-Party Model Pricing
 See the full pricing breakdown for all available models from OpenAI, Anthropic, Google, xAI, Z.AI, Moonshot AI, and NVIDIA, including cache rates and provider documentation links on the Agent API Models page .
