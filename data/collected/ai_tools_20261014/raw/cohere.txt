요금은 선택한 모델과 성능 계층에 따라 인스턴스별로 결정됩니다. 청구는 시간별 또는 장기 약정(월별 또는 연별)으로 계산할 수 있습니다.

 모델 커스터마이징 및 프라이빗 배포 문의 방법은 어떻게 되나요?
 코히어는 엔터프라이즈 고객을 대상으로 맞춤형 모델 커스터마이징과 모든 제품의 프라이빗 배포를 지원합니다. 맞춤 가격은 엔터프라이즈 요구 사항에 따라 책정됩니다. 커스터마이징에 대한 자세한 내용은 여기 를, 프라이빗 배포에 대한 자세한 내용은 여기 를 참고하세요.
 트라이얼 API 키는 어떻게 발급받나요?
 계정을 생성하면 자동으로 트라이얼 API 키가 발급됩니다. 이 API 키는 대시보드에서 복사할 수 있으며, “API 키” 섹션에서도 확인할 수 있습니다.
 프로덕션 API 키는 어떻게 발급받나요?
 프로덕션 키를 발급받으려면 소유자 권한이 필요합니다(또는 조직의 소유자에게 다음 단계를 요청하세요). 코히어 대시보드의 청구 및 사용량 페이지로 이동한 후, “프로덕션 키 발급” 버튼을 클릭하고 프로덕션 워크플로를 완료하세요.
 트라이얼 API 키와 프로덕션 API 키의 차이점은 무엇인가요?
 트라이얼 API 키를 사용한 API 호출은 무료입니다. 하지만 트라이얼 키는 사용량이 제한되며, 프로덕션 또는 상업적 목적으로 사용할 수 없습니다. 프로덕션 API 키를 사용한 API 호출은 종량제 방식으로 과금됩니다. 프로덕션 API 키는 대규모 프로덕션 사용에 적합합니다.
 계정 생성 시 제한 사항이 있나요?
 모든 계정은 개인 계정으로 시작되며, 트라이얼 API 키만 사용할 수 있습니다. 개인 계정에서는 조직에 속하지 않는 한 다른 멤버를 추가할 수 없습니다.
 조직 계정과 개인 계정의 차이점은 무엇인가요?
 코히어에서 조직은 단일 청구 포털을 공유하는 개인 계정의 그룹입니다. 조직은 자동으로 프로덕션 API 키 접근 권한을 부여받지 않으며, 조직의 멤버가 프로덕션 접근을 위해 신청서를 제출해야 합니다. 개인 계정은 다른 계정과 청구 정보를 공유할 수 없습니다.
 어떤 모델을 선택해야 하나요?
 모델 선택은 성능과 속도에 대한 우선순위에 따라 달라집니다. 대형 모델은 더 나은 성능을 제공하고 복잡한 작업을 처리할 수 있지만, 소형 모델은 응답 속도가 더 빠릅니다.
 청구 시점은 언제인가요?
 트라이얼 API 키를 사용한 API 호출은 무료입니다. 프로덕션 키를 사용한 API 호출은 종량제 방식으로 과금되며, 매월 말일 또는 미수금이 $250에 도달할 때 청구서가 발행됩니다.
 사용 중인 엔드포인트가 토큰 기준으로 과금된다고 하는데, 토큰이란 무엇인가요?
 언어 모델은 문자나 바이트가 아닌 “토큰”을 사용합니다. 단어당 토큰 수는 텍스트의 복잡성에 따라 달라집니다. 간단한 텍스트는 평균적으로 단어당 1토큰에 가까울 수 있지만, 복잡한 텍스트는 덜 일반적인 단어를 사용해 평균적으로 단어당 3~4토큰이 필요할 수 있습니다. 토큰에 대한 자세한 내용은 이 페이지 를 참고하세요.
 레거시 모델의 가격 정보는 어디서 확인할 수 있나요?
 기존 고객 대상:
 Command 가격: 입력 $1.00/1M 토큰, 출력 $2.00/1M 토큰
 Command-light 가격: 입력 $0.30/1M 토큰, 출력 $0.60/1M 토큰
 Command R 03-2024 가격: 입력 $0.50/1M 토큰, 출력 $1.50/1M 토큰
 Command R+ 04-2024 가격: 입력 $3.00/1M 토큰, 출력 $15.00/1M 토큰
 Command R+ 08-2024 가격: 입력 $2.50/1M 토큰, 출력 $10.00/1M 토큰
 API를 통해 연구용 Aya 모델에 접근하는 비용은 어떻게 되나요?
 API를 통한 Aya Expanse 모델(8B 및 32B) 사용 비용은 입력 $0.50/1M 토큰, 출력 $1.50/1M 토큰입니다. Aya 모델에 대한 자세한 내
