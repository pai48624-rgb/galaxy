 FAQ
Frequently Asked Questions
 What's included in the free Individual plan? Everything you need for personal use: the full Nimbalyst editor, session manager, Claude Code and Codex AI integration, MCP server support, extensions, file link sharing, mockups, diagrams, data models, and git worktrees. No feature limits, no trial period. 
 Do I need my own API key or subscription for AI features? Yes. You bring your own AI access and Nimbalyst provides the workspace and tools around it. Your access can be a subscription like Claude Code or Codex, an API key from Anthropic, OpenAI, or other providers, or local models through LM Studio. Nimbalyst connects to whichever you already have. See how Claude Code and Codex access works →
 What does the Teams plan add? The Teams plan adds real-time collaboration: edit shared docs, mockups, and diagrams together, manage tasks and trackers as a team with your agents working the same board, and control workspace access with admin tools. 
 How much does Teams cost? Teams is $20 per user per month, or $200 per user per year. Teams is in Beta right now and free to use while it is, so you can bring your whole team in and try collaboration on real work before you pay anything. 
 When does a team need the Enterprise plan? When the collaboration server has to run inside your own cloud rather than ours, when your security review needs to read the source of what runs in your account, when data residency has to be pinned to a jurisdiction, or when you want editors built for your own artifacts with one of our engineers embedded alongside your platform team. Pricing is custom and starts with a conversation. Talk to us about Enterprise →
 How do we get into the Teams Beta? Download Nimbalyst, sign in, and create a team from the app. Invite your teammates by email and shared docs, trackers, and boards work across everyone immediately. No approval step and no card required.

## Nimbalyst Features

- AI-native workspace for human + AI collaboration
- AI agents that stream edits directly into open editors in real time
- Multi-editor environment for code, markdown, spreadsheets, diagrams, and visual docs
- Extension-first architecture for custom editor/file-type support
- Local-first file model using open formats like Markdown, JSON, and CSV
- Code-aware agent orchestration for implementation planning and task execution
- Git worktree isolation for safer parallel AI coding sessions
- Rich markdown editing with tables, code blocks, embeds, and formatting tools
- Monaco-based code editing experience for programming workflows
- RevoGrid-powered spreadsheet editing for CSV and tabular workflows
- Excalidraw integration for diagram and whiteboard workflows
- Visual data modeling tools for schema-centric work
- Visual mockup editing for interface ideation and iteration
- Unified editor lifecycle with consistent AI integration across editor types
- Auto-save and file watching for reliable local development workflows
- Project-level workspace management and AI session tracking
- Built on production-grade desktop foundations with Electron

## FAQ

- **Is Crystal discontinued?** Yes. Crystal is deprecated and replaced by Nimbalyst.
- **Can I still use Crystal?** Yes. You can continue using Crystal, but we recommend moving to Nimbalyst for active updates.
- **Where is Nimbalyst?** https://nimbalyst.com/

For downloads, documentation, and updates, go to **https://nimbalyst.com/**.
