 Agent Network Protocol Open protocol stack for the Agentic Web 
 Decentralized identity, discovery, messaging, and payment protocols for interoperable AI agents.
 Read the Specs 
 Get Started 
 GitHub 
 ID
 Decentralized identity
 did:wba and WNS provide verifiable agent identity, readable handles, and cross-domain trust roots.
 AD
 Description and discovery
 Agent descriptions and discovery protocols let agents publish capabilities and find interoperable services.
 IM
 End-to-end messaging
 The messaging profiles define direct chat, groups, encryption, attachments, and federation semantics.
 AP
 Domain protocols
 Domain protocols build on ANP identity and communication foundations for payment, authorization, authentication, and vertical workflows.
 Protocol stack
 From identity to application protocols
 ANP is organized as a layered protocol suite so implementations can adopt the foundation first, then add messaging, discovery, and payment capabilities as needed.
 Base Open infrastructure
 ANP reuses the open Internet foundation: HTTP, CA, DNS, CDN, Search, TLS, and existing web deployment patterns.
 02 / 03 / 04 / 09 Identity and communication
 DID:WBA, WNS, authentication, key distribution, and secure messaging form the cross-domain infrastructure layer.
 07 / 08 Description and discovery
 Agents describe services, capabilities, endpoints, and discovery mechanisms in a way other agents can consume.
 09 / P1-P9 Messaging profiles
 Direct messaging, group messaging, E2EE, attachments, and federation are split into focused profiles.
 Domain Domain protocols
 Payment, authorization, authentication, commerce, and other vertical protocols sit at the application layer.
 Architecture
 Designed for open, cross-domain agent networks
 ANP 1.2 builds on open Internet infrastructure with identity and encrypted communication foundations and domain-specific application protocols.
 Open Internet infrastructure The bottom layer reuses HTTP, CA, DNS, CDN, Search, TLS, and the existing web operating model. Identity and communication infrastructure The middle layer provides DID:WBA identity, WNS handles, authentication, key material, secure messaging, and cross-domain communication foundations. Application protocol layer The top layer includes Agent Description, Agent Discovery, and domain-specific protocols for payment, authorization, authentication, commerce, and other agent workflows. 
 Latest protocol updates
 New specifications now available
 New DID authentication
 ANP-02 defines method-independent request authentication for did:wba and native did:web.
 New Messaging 1.2
 The updated profile set covers direct messages, groups, device-bound E2EE, attachments, and federation. P6 remains a candidate.
 Updated WBA Name Space
 Human-readable handles such as alice.example.com map to did:wba identities with bidirectional verification.
