⚙️ Supabase 연결 설정이 필요해요

index.html 상단 CONFIG 에서 두 값을 채우세요:

const CONFIG = {
  SUPABASE_URL: "https://여기에-프로젝트-ref.supabase.co",
  SUPABASE_ANON_KEY: "여기에-publishable(anon) 키",
};

값은 Supabase 대시보드 ▸ Project Settings ▸ API 에 있습니다. 그다음 supabase_schema.sql 실행 → npm install && npm run import 순서로 진행하세요.
